# Интерактивная схема метро Софии

Рабочий локальный прототип с интерактивной SVG-схемой, выбором A/B, поиском по болгарским и латинским названиям, маршрутизацией, оценочным временем, compact/full legend, синхронной анимацией, URL/history, карточками станций, zoom/pan и отдельной mobile-компоновкой.

## Запуск

```powershell
cd C:\SofiaMap\metrotest
npm run dev
```

Откройте URL Vinext (обычно `http://localhost:3000`). Production-проверка: `npm run build`. Тесты: `npm test`.

## Архитектура и каталоги

- `app/page.tsx` — state-controller, desktop/mobile UI, SVG renderer, URL и animation lifecycle.
- `lib/metro-data.ts` — линии, станции, соседства, переходы и поиск пути.
- `app/globals.css` — визуальные токены и отдельные desktop/mobile layout-сценарии.
- `public/reference/sofia-metro-reference.png` — только источник визуального сравнения; приложение не использует PNG как карту.
- `tests/metro.test.mjs` — проверки целостности исходной модели.

| Класс | Источник | Статус |

## Топология

M1 и M4 используют общие station id на общем западно-центральном коридоре. Ребро хранит line id; продолжение той же линии не считается пересадкой, смена линии получает штраф. Явные transfer: `Сердика ↔ Сердика II`, `НДК II ↔ НДК`, `СУ Св. Климент Охридски ↔ Орлов мост`. Устойчивые station id напрямую связаны с SVG-группами и сегментами.

## Расчёт, легенда и lifecycle

Поиск вариантов работает по ride/transfer-графу с приоритетной очередью. Цена ride — оценочно 2 минуты, transfer — 4–5; +2 минуты на вход и выход добавляются один раз. Compact объединяет последовательные ride одной линии, full показывает каждый перегон. При смене маршрута интервал очищается и старый run не продолжает менять состояние. В reduced motion весь маршрут сразу завершён.

## URL, accessibility, desktop/mobile

Query хранит `a`, `b`, `v`, `station`, `popstate` восстанавливает их. Станции — SVG-кнопки с focus, Enter/Space и доступными именами. Desktop имеет левую панель; mobile использует карту, нижнюю навигацию, sheet, крупные touch-зоны и safe-area.

## Ограничения

- SVG является семантической реконструкцией основных линий и станций, не пиксельной трассировкой всех декоративных элементов.
- Оценочные времена, доступность лифтов, временные статусы и точные географические координаты требуют проверки.
- Сеть надо обновлять при вводе новых участков.

Московский проект использован только read-only как технологический и UX-референс и не изменён.
